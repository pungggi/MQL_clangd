Arrange Charts New

Snap your MetaTrader 5 chart windows into a layout — directly from VS Code, for docked and undocked (floating) charts alike.

Run MQL: Arrange MT5 Charts from the Command Palette, or click the ⚗ Charts button in the status bar (bottom-right). A notification reports what moved, e.g. docked 6/6 on mon 2 (2×3); floating 2/2 on mon 1.

Why use this?

  • No dragging windows: One command tiles every open chart into your saved layout — across monitors, including the charts you undocked.
  • Paint instead of JSON: The new visual preset editor (MQL: Edit Chart Layout Presets (Visual)) lets you drag-paint the grid — timeframes, empty cells, custom regions — with a live settings preview.
  • Layout modes: All-timeframe grids bind each region to your active symbol's chart of that timeframe; anything else fills charts in reading order. Extra charts are tucked away minimized.
  • Clear feedback: Regions that found no chart are reported as [missing: W1, M30] so you know exactly what to open.

Step-by-Step Guide

  • Paint your layout
    Run MQL: Edit Chart Layout Presets (Visual) and drag across cells to fill rectangles — one card for docked charts inside the MT5 window, one for floating charts on another monitor. Or edit mql_tools.ChartLayout.Presets by hand (three presets ship out of the box).
  • Save & apply
    Save to Settings writes the preset list; ▸ Apply Now saves and immediately arranges the charts so you can iterate until it feels right.
  • Arrange anytime
    With MT5 running, run MQL: Arrange MT5 Charts and pick a preset — or use the status-bar button, which remembers the last layout you applied.

Good to know

  • Timeframe regions accept long aliases too: Daily, Weekly, Monthly behave like D1/W1/MN1.
  • Arranging is Windows-only (it positions native MT5 windows) and never closes a chart — extra charts are just minimized.

Settings Reference

Setting Default Description
mql_tools.ChartLayout.Presets wall, quad, focus The preset list. Each preset has a docked grid (and optionally a floating grid) with a monitor, an areas template or rows×cols, and a gap.
mql_tools.ChartLayout.ShowStatusBarButton true Show / hide the ⚗ Charts status-bar button.
